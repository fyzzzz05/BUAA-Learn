# Windows 全文分析执行记录

日期：2026-11-01。W12 的本机实现与合成链路已验证；Windows 编译、WebView2 原生运行和真实模型请求继续延后。

## 已实现

`CoreLearning` 接入现有 `buaa_core_analyze_lesson`，同步回调只在队列工作线程内使用。委托为静态根，调用上下文以 GCHandle 固定；回调响应使用配套 CoTaskMem 分配/释放，Rust 返回值恰好释放一次。回调捕获托管异常，不跨越 ABI；取消、进度回调失败与模型传输失败保留为终止原因。只有无效 JSON/响应允许进入内核有限修复循环；即使内核的可选主题修复产生部分结果，也不能掩盖网络、鉴权、额度、拒绝或截断失败。

`LearningService` 注册离线可执行的 `analyze` 串行任务。任务从固定账号读取课程、课次与完整材料，检查可用文本及摘要后捕获独立模型配置/凭据。全文交给 Rust 分批，不截断末尾，不发送截图。单次 HTTP 最长 180 秒、整节分析最长 30 分钟；账号切换、队列停止/窗口关闭会将取消传递到实际 HTTP。执行中的配置快照保持不变，设置变化不会重定向旧请求。模型传输由宿主在任务排空后释放。

分析完成后调用 `buaa_store_save_analysis_checked`，在同一事务中检查材料摘要、课程归属，并保存分析、完整引用原文、作业对账及课次 `analysis_at`。材料变化、模型失败、引用无效、取消和保存失败不会以候选结果替换旧笔记。刷新材料后仍使用分析自己的原文快照查看来源。

## 页面

沿用本地 React Base UI 工作区。课堂阅读器增加“生成笔记/重新分析”，无文本或模型配置不可用时禁止提交。真正提交前显示课堂文本发送与费用提示，消息桥要求 `acknowledge_cost: true`；保存设置不发起课堂模型请求。

顶部和阅读器继续使用同一任务状态。结果仅显示时间轴；知识点、作业和事项附在对应课堂时间段内，并可查看来源或完整原文。部分整理保留明确状态和未归类原文，不显示成完整整理。课次列表使用内核实际保存的 `analysis_at`，兼容已有 `analyzed_at`。

开发预览只引用测试项目中的合成模型 HTTP handler，不访问真实模型。预览以周期通知代替 WinUI 的宿主推送；此适配器不进入 Windows 发布资源。
