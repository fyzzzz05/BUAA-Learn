# Windows 迁移：正式工作区登录适配

日期：2026-11-01。对应 W04/W08/W09 的宿主接线，Windows 真实 SSO 验收仍延后。

## 已接入的路径

业务页面发起 `connect` 后立即返回登录状态，由 `SchoolLoginController` 在独立操作中打开 `SchoolBrowserWindow`。业务消息桥不等待用户输入；重复开始复用当前操作，取消登录、选择本地账号和退出登录会协调终止旧登录。业务页通过状态通知刷新，不轮询学校网络。

学校窗口使用独立临时资料目录和 InPrivate profile。禁止 WebMessage、HostObject、权限请求和下载；密码只在学校页面输入。仅在教学空间允许的顶层来源执行捕获脚本，并在脚本返回后再次检查来源。捕获学生身份后仍须通过实际学期请求校验，才注册账号、连接队列并获取可用学期；不默认选择第一学期。

学校会话保存的录播授权器会重新打开该独立窗口处理每门课程的签名入口。每次授权重置目录编号并清理旧录播凭据，观察到本次入口导航后才接受后续课程编号。只有实际目录请求成功后服务才建立录播绑定。手动关闭窗口或授权超时不会当作目录成功，也不会清空已有目录或使教学空间会话失效。

`SchoolConnection` 统一拥有其浏览器资源。失败、退出、切账号和应用关闭都会释放；窗口销毁派发到 UI 线程。`BrowserProfileLease` 在私有缓存目录创建随机资料目录并锁定租约；其他活跃窗口的目录不会被清理，异常退出的生成目录在下次启动清理。浏览器进程尚未释放的目录可留待下次重试，不能宣称完全不触盘。

登录提交使用账号和转换版本票据。即使用户重新选择同一个离线账号，旧窗口的晚到结果也会被拒绝；候选身份不会被注册。队列取消旧任务并等待退出期间收到取消时，提交前再次检查令牌，保持原账号离线，不注册候选账号。已完成提交以实际连接状态为准。

原始回放入口通过宿主从固定账号的课次编号生成已知学校 `livingroom` 地址，交给系统浏览器。页面不能指定任意网址或本机路径，存储中的任意 `source_url` 也不会被直接启动。该入口不传递学校或模型凭据；系统浏览器可能要求用户自行登录。

## 验证

| 检查 | 结果 |
| --- | --- |
| C# 共享检查 | 40 项通过，包含登录非阻塞/去重/取消、失败身份不注册、同账号重选拒绝旧登录、队列退出期间取消、资源释放和资料目录租约 |
| 录播取消 | 保留教学空间连接与旧目录，不发起目录请求；可重新同步 |
| 回放入口 | 忽略不可信存储 URL，拒绝无效编号；固定学校地址 |
| TypeScript / 生产与预览打包 | 通过；原有 Base UI 组件约定保留 |
| WinUI C# API 检查 | 真实 SDK 引用、InitializeComponent stub 编译通过，没有执行 XAML 编译器 |
| 浏览器 | 实际消息桥与临时 Rust SQLite，合成等待中的登录器：连接 → 登录中 → 取消 → 恢复连接入口，旧课程保留 |
| Windows / 真实 SSO | 未运行，不能由以上合成结果推定通过 |

浏览器检查通过 Ego Lite 的同一任务空间完成，截图 `/tmp/buaa-windows-login-cancel.png` 仅为本机 QA。测试预览不打开真实学校窗口，也不模拟成功认证；不能算作学校链路验收。
