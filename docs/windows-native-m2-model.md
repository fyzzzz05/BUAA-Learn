# Windows 迁移：模型配置、凭据与传输

日期：2026-11-01。对应 W11 的本机实现与合成验证；Windows Credential Manager 真机验收未执行。

## 已交付

`ModelEndpoint` 对齐现有 `learning.py` 的两类协议：DeepSeek 官方根地址或 `/v1` 使用 Responses，其余地址使用 Chat Completions。仅接受 HTTPS，或 localhost/127.0.0.1/IPv6 loopback 的本地 HTTP；拒绝地址中的用户信息、查询串、片段与控制字符。主机大小写、默认端口、尾斜杠规范化，保留有语义的路径和端口，不擅自改写提供商接口。

模型服务、模型名称与非敏感凭据引用写入固定账号的 Rust SQLite `meta`。密钥按账号、规范化服务地址和随机版本引用定位到 Windows Generic Credential；配置中不存密钥。更换地址不会复制旧地址密钥，返回此前保存的地址可继续使用其自己的密钥；即使复制 SQLite 引用到另一账号，也不能读到原账号凭据。模型配置使用对象版本 1，未知版本拒绝修改。

保存新密钥前先持久化待清理候选引用，再写系统凭据，最后在单个 SQLite 批次中更新配置及活动引用。提交前的写入或取消失败保留旧配置及活动密钥；未能删除的候选引用保持可追踪。替换或移除后，旧版本引用进入清理列表，删除失败可重试，不将“配置已更新”等同“所有旧密钥已彻底删除”。清理前检查引用是否仍活动，包含大小写规范化，避免误删当前密钥。

移除密钥有独立命令，不会顺便保存尚未提交的模型名称或地址草稿。系统凭据无法读取时，原引用不会被静默抹掉；本地阅读和其他非模型功能仍可使用。

`WindowsModelCredentialStore` 使用 `CredReadW`、`CredWriteW`、`CredDeleteW` 与 `CredFree`，仅从 System32 加载。Generic blob 使用 UTF-8，并限制在 2560 字节；使用当前 Windows 用户在本机的持久化范围，不使用漫游设置。读取/写入暂存字节会清理，模型调用快照结束时清理所持字节；没有全局明文 Key 缓存。HTTP 鉴权仍需要短暂的托管字符串，不承诺进程内存的取证擦除。接口依据：[CREDENTIALW](https://learn.microsoft.com/en-us/windows/win32/api/wincred/ns-wincred-credentialw)。

`ModelTransport` 与学校客户端独立：不复用 Cookie、学校凭据、代理凭据或可变默认鉴权头；禁止重定向、使用默认 TLS 校验、180 秒请求期限与 32 MiB 响应上限。请求格式与响应解析实际调用 Rust ABI，本地无 Key 模型不发送 Authorization。鉴权、额度、网络、超时、截断、拒绝和格式错误可区分；不回显服务错误正文或无限重试。

Rust 模型/分析错误 envelope 新增稳定 `error_code`，不改 major ABI。输出截断和拒绝不会被宿主误标为可修复 JSON 错误，供后续分析队列控制重试；现有 Swift 读取仍兼容。

## 页面

“模型与设置”已接入侧栏。地址、模型名称、API Key 三个字段与保存、独立移除操作使用当前账号。密钥只显示保存状态，输入框始终不回填；保存后、编辑地址、切账号及会话上下文变化时清空未保存的密钥。只有实际存在旧密钥清理失败时才显示重试入口。

首次没有本地账号时提示先连接学校建立账号；已有本地账号可离线进入设置。保存配置不会向模型服务发送课堂内容或发起付费测试请求，`ready` 只表示本地配置/凭据可用，不是模型连通性验收。
