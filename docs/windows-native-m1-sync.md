# Windows 迁移：学校同步与离线阅读服务

日期：2026-11-01。对应 W08 与 W10 的部分共享服务；Windows 编译、真实学校登录、业务页面集成未完成。

## 已实现并验证

`SchoolSyncRuntime` 统一持有固定账号的学校会话、串行任务队列和离线读取接口。学期必须明确选择；学校课程、过去 7 天至未来 21 天的真实课表在成功读取后一起事务保存，按北京时间计算日期，不推算每周课程。合法空课程快照隐藏已消失条目，但保留旧材料；响应异常不覆盖上次有效快照。

录播授权通过 `IRecordingAuthorizer` 交给宿主，实际目录读取成功后才绑定该课程的录播状态。目录与课程统计一次事务合并；拒绝把别的课程已占用的课次重新归属。录播子课编号用于材料接口，零时间保留未知日期。学校凭据和签名入口只在内存使用，任务记录不包含它们。当前自动测试的授权器为合成实现，不能证明真实 SSO。

材料通过真实 Rust C ABI 获取，包含 ASR、分页 PPT 索引、覆盖情况和清理查询串的资源地址。新增 `buaa_store_save_materials` 验证账号/父课程/录播编号、片段、图片、时间和摘要，事务保存材料与课次统计；数据库第二次写入失败会回滚第一次写入。空材料、网络失败、摘要篡改和登录过期均保留已有有效材料。旧分析 evidence 始终不被材料刷新覆盖。

任务取消令牌经 `CoreSchool` 的托管作用域传到实际 `HttpClient` 请求，也传到等待中的录播授权。账号切换先取消并等待旧工作退出，再换连接；后台任务不能读取可变的当前会话。学校连接过期映射为需登录，停止后续学校任务。窗口适配器后续必须通过 runtime 切换账号，不能绕过它直接修改 `Jobs` 的连接状态。

`LessonReader` 可离线搜索中英文原文，读取分析保存的 evidence 并解析引用范围。缺失或倒序引用返回空，不把新材料当作旧来源。阅读标签、搜索词、锚点、滚动位置按固定账号/课次/标签写入同一 SQLite；恢复时快照已变则保留搜索词并安全重置位置，不猜测新锚点。截图下载与缓存、可见阅读器仍待实现。

W09 已建立 `WorkspaceBridge` 的受限协议服务：精确本地页面来源校验、版本/大小/字段校验、命令白名单、固定账号读取与任务入队。账号切换与桥读取/入队共用 runtime 转换锁；50 轮并发切账号/读取检查不会把另一账号课次标为原账号结果。远程来源不响应，未知/任意文件命令拒绝。此服务尚未附加到 WebView2，后续适配器仍必须禁止远程导航、iframe、弹窗与下载并设置 CSP，不能把服务测试当成浏览器隔离完成。

## D01 的最终选择

用户明确选择“Windows 也继续使用 React Base UI”。现有 AGENTS.md 不改；业务页面使用独立本地 WebView2，复用 Base UI Combobox、SidebarProvider/Sidebar/SidebarTrigger 和 Checkbox/Switch。WinUI 负责窗口和系统操作，Rust/C# 负责业务。学校远程页面与本地业务桥必须隔离。原无业务 WebView2 的内存估算不再适用；PRD v0.5 已同步调整。
