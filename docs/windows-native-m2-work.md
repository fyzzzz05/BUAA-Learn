# Windows 作业与事项

W13 本机实现于 2026-11-06 验证。

侧栏新增“作业与事项”。作业按当前和已被替代分开，当前作业使用共享 Base UI Checkbox 勾选完成。截止、提交和适用对象沿用已提取的字段，作业显示待核验。事项按课堂汇总，作业与事项的来源链接均可打开对应课次的原话，并进入该课堂。

Rust 在账号事务内更新作业完成字段，保留重分析写入的其他字段。沿用同课次、同文本的现有作业标识及完成状态。新标识采用有明确边界的课次与文本组合。改写项独立创建，移除项进入历史，历史作业保留自己的课堂证据快照。一次分析的作业共用一份快照。升级前已有的当前作业若能与旧分析精确匹配，会在重分析前保存当时的来源。已经缺失证据的历史作业会显示来源不可核验。

事项列表跨 ABI 只读取事项与课次摘要。事项来源绑定当前分析版本，重分析后旧链接需要从列表重新打开。

Rust 67 项、C# 59 项和 Swift 43 项通过。C# 新增跨消息桥的重分析检查，覆盖保留、改写、移除、旧原文、勾选和取消、事项旧链接及账号隔离。TypeScript、Windows 资源构建和 WinUI C# API 静态编译通过。浏览器合成预览确认键盘勾选、刷新后保留、历史和事项来源跳转，以及 640 像素窗口内无横向溢出。
