## 在 Windows 11 x64 记录证据

1. 记录源码 commit、安装包 SHA-256、Windows/CPU/内存、WebView2 版本、屏幕 DPI 和电源设置。
2. 运行 `build.ps1 -Publish`，用 `package.ps1` 生成测试安装包，使用两个版本执行 `setup-smoke.ps1`。正式签名需真实签名身份及时间戳验证。
3. 用 `startup-samples.ps1` 记录 20 次合成离线课程启动。另采集真实账户热启动和五次独立冷启动，分开记录。以同机、同账号、同场景分别采样 Electron 与原生，保留所有 WebView2 和 Electron 子进程。
4. 运行 `process-samples.ps1` 记录 5 分钟空闲，再记录 8 小时同步、阅读及休眠恢复。注明进程退出、失败、长时间内存增长和句柄变化。
5. 执行 A01–A22 并附脱敏证据。真实学校登录由账号本人完成，证据中排除凭据、课堂正文和授权链接。对照 PRD 的发布门槛，缺项和失败项保留在 GitHub Issues。
